# Tenisový klub Louny — návrhy nového webu

**Náhled:** https://petrluxa.github.io/louny/

Tři návrhy úvodní stránky nového webu tenis-louny.cz. Obsah je u všech stejný, liší se náladou a hlavním nápadem:

- **01 Červená** — světlá moderní, červená z padelového kurtu a modrá
- **02 Almanach** — světlá klasická, tradice od roku 1927
- **03 Nadhled** — tmavá, areál z dronu a interaktivní plánek

Texty, ceny a fotky pocházejí ze současného webu klubu. Obsazenost kurtů je ukázková.
